VANGUARDIAS LATINOAMERICANAS - BLOG EDUCATIVO

Archivos incluidos:
- index.html -> Página principal
- mexico.html
- argentina.html
- brasil.html
- chile.html
- colombia.html
- peru.html
- css/style.css -> Estilos generales para todas las páginas

Cómo usar:
1. Descomprimir el archivo ZIP.
2. Abrir la carpeta en Visual Studio Code.
3. Abrir index.html con Live Server o directamente en el navegador.
4. Todos los enlaces entre países ya están conectados.

El contenido es una base educativa editable. Podés reemplazar textos, agregar imágenes, videos y producciones de los estudiantes.
